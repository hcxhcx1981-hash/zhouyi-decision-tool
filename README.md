# 周易决策工具

一个手机优先的本地 Web 项目骨架，面向八字资料整理与六爻问事的规则研究、交互原型和确定性计算能力建设。它不提供或承诺任何预测结论；结果仅供学习、研究与个人决策参考。

## 开源状态

当前发布为 **V0.1**：包含可运行的本地 Web 骨架、冻结规则数据、UI、文档与测试。项目以 [MIT License](LICENSE) 开源；欢迎通过 Issue 或 Pull Request 提交可复现的问题、规则资料来源、文档与测试改进。提交前请勿包含凭据、真实个人资料或自动生成目录。

## 功能范围

- **八字模块**（`/bazi/`）：提供出生资料输入界面；历法转换、四柱排盘与解释规则仍处于持续建设中，当前不会生成虚构命盘。
- **六爻模块**（`/liuyao/`）：支持自下而上手动录入六爻，并展示本卦、之卦、动爻、占变路由与已冻结的乾、坤、屯规则证据。
- **规则与测试**：仓库包含冻结的规则数据、研究文档、确定性运行时代码和回归测试。

六爻纳甲、世应、六亲、六神、用神、旺衰及事情进展/结局解释目前尚未实现。项目不提供“保证准确”的预测，也不应作为医疗、法律、财务或其他高风险决策的唯一依据。

## 本地运行

前提：Node.js 与 npm。

```powershell
npm install
npm run dev:3036
```

然后打开 <http://127.0.0.1:3036>。也可运行项目内的 `start-dev.bat`。生产构建：

```powershell
npm run build
npm start
```

## 自行配置模型/API（可选）

本项目**不提供 API、模型账号或密钥**。如后续功能需要模型服务，请自行准备合法可用的服务，并优先使用 OpenAI-compatible 接口；项目不绑定 Agnes、OpenRouter、DeepSeek、Gemini 或任何特定供应商。

从示例创建本地配置（不要提交生成的 `.env.local`）：

```powershell
Copy-Item .env.example .env.local
```

`.env.example` 仅包含以下无值占位符：

```dotenv
OPENAI_BASE_URL=
OPENAI_API_KEY=
OPENAI_MODEL=
```

请只在本机填写真实值。`.env*`（除 `.env.example` 外）被 Git 忽略，严禁将 API Key、Token、Cookie、账号凭据或真实供应商配置提交到仓库。

## 当前状态与已知限制

项目目前聚焦于产品架构、规则协议、确定性引擎与移动端交互；八字页面尚未接入完整排盘链路，六爻高级规则层也尚未完成。默认不接入 AI、网络占断、数据库、登录、支付、随机起卦或铜钱模拟。冻结资料位于 `data/frozen/`，相关架构与阶段说明见 `docs/PRODUCT_ARCHITECTURE_V0.1.md`。
