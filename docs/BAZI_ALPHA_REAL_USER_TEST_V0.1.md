# 八字真人 Alpha 测试 V0.1

## 目的

验证基础命盘页面是否能让真实测试者完成排盘、理解当前展示内容，并识别下一步最需要澄清的边界。测试只评估当前已实现的基础排盘与结构说明，不评估或推导旺衰、身强身弱、喜用神、格局、大运、流年，以及事业、财富、婚姻或健康预测。

## 测试前说明

1. 测试者在自己的设备上输入资料，并自行核对可信排盘结果。
2. 组织者不收集、记录、截图、复制或传输出生日期、出生时间、地点、完整四柱、姓名或联系方式。
3. 测试结束后，只保留下列匿名反馈字段；页面资料不应写入 localStorage、sessionStorage、IndexedDB 或 Cookie。

## 测试流程

1. 打开 `/bazi/`，填写出生资料并生成基础命盘。
2. 测试者自行将四柱与其可信排盘结果对照。
3. 依次阅读：四柱、日主、命盘结构、十神白话解释、月令/通根事实、当前判断边界。
4. 尝试“复制基础命盘报告”，确认复制操作只在本次点击时发生。
5. 仅记录下方匿名反馈，不记录输入资料或完整命盘内容。

## 匿名反馈记录

| 字段 | 允许值或填写方式 |
| --- | --- |
| `CHART_CORRECT` | `YES` / `NO` / `UNSURE`；仅记录是否与可信排盘结果一致。 |
| `UNDERSTAND_SCORE` | `1`–`5`；对当前内容的看懂程度。 |
| `VALUE_SCORE` | `1`–`5`；当前内容的实际价值。 |
| `MOST_CONFUSING_SECTION` | 最难理解的模块名称，不附带命盘内容。 |
| `FIRST_FOLLOWUP_QUESTION_CATEGORY` | `整体怎么样` / `身强身弱` / `事业` / `财富` / `感情` / `大运流年` / `其他`。 |
| `WOULD_USE_AGAIN` | `YES` / `NO`。 |
| `NOTES` | 可选匿名意见；不得包含姓名、生日、详细地址、完整四柱或联系方式。 |

## 记录与复核规则

- `CHART_CORRECT=NO` 时，只记录“未一致”与可复现的非个人化测试条件；不得记录真人输入资料。
- `NOTES` 出现隐私内容时，立即删除该条内容，不进入汇总。
- 汇总只使用字段值与去标识化的模块反馈；不得关联设备、身份或联系方式。
- 本轮结论只用于评估基础命盘主链、可理解性和后续问题类别，不产生任何个人命理解读。
