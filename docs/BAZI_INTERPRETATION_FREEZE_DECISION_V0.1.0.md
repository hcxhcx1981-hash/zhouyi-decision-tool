# 八字 SAFE Interpretation Protocol V0.1.0 冻结决策

## 决策范围

本次冻结是对研究候选的人工审核投影，不是整包照搬。正式运行时仅收入 7 个 SAFE Interpretation 单元：日主、七杀、伤官、正官、正印、食神、正财。状态为 `FROZEN_RUNTIME_DATA`，传统范围为 `ZIPING_BAZI`。

生成器中的 `FREEZE_POLICY_V0_1` 固定保存获批文案，研究候选只提供术语与 `source_id` 证据链。正式数据以研究来源登记 SHA-256 和候选 SHA-256 追踪证据，不复制古籍原文或网页内容。

## 为什么没有照搬研究候选

研究结论包含候选表述、证据讨论和仍需政策裁决的边界。运行时协议只保存经过终审批准且足够窄的表达。研究曾建议的劫财主题本次未获批准，因此与比肩、偏财、偏印一并保持 `FACT_ONLY`；四者只能展示 Foundation 已冻结的生克阴阳结构分类依据，不能显示 SAFE 主题。

正印被收窄为“生身关系”，不收入智虑、贵人、长辈庇护、学习能力或聪明。食神被收窄为“食禄 / 生财关系”，不收入福气、享受、才华、表达、有口福或长寿。正财被收窄为“财帛关系”，不收入正当收入、稳定财富、勤劳、务实、有钱或妻财个人断语。

## Gate 与结构边界

正式 Gate 只有：

- `FACT_ONLY`：可直接显示确定结构事实。
- `SAFE_SEMANTIC_GLOSS`：只能使用正式冻结的 safe gloss。
- `CONTEXT_REQUIRED`：只能提示需要更多传统规则后才能进一步判断，不能输出结论。
- `PROHIBITED_DIRECT_INFERENCE`：禁止生成。

CASE-I11 收口为 `FACT_ONLY`。透干与藏干只允许陈述“出现在天干”“仅存在于地支藏干”或“同时存在”；不得声称透干更重要、更强、更直接，或藏干更弱、深根更有力。

数量规则固定为 `COUNT_ONLY_IS_NOT_INTERPRETATION`。数量只能作为事实，例如“命盘中有两个可见七杀关系”，不能据此输出“重、旺、压力大、杀气重、事业心强”等解释。

## 产品边界

本次冻结不是个人命理解读，也不提供性格、事件、吉凶或人生结果。旺衰、月令、通根、生扶克泄、格局、制化、位置和全局组合仍属于 `CONTEXT_REQUIRED`；喜用神、大运和流年不在本协议范围。

下一阶段可以基于正式协议开发 SAFE 展示层，但必须逐字消费冻结文案并执行禁语 Gate。仍不允许开发个人化命运判断，也不得据单一十神、数量、透干或藏干生成结论。
